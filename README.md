# Room Booking Demo

A Java Swing desktop demo with three sample meeting rooms. Select a room, date, and time slot, then book it under your name. The app blocks duplicate bookings for the same room, date, and time. Select a booking in the table to cancel it.

## Run

From this folder, use JDK 17 or later:

```powershell
java dashboard.java
```

Bookings are stored in memory and reset when the app closes. No database or external libraries are required.

Search bookings by any table column or click a column heading to sort.
